# VK AI-бот (VKBottle)

MVP-бота для сообщества ВКонтакте, который демонстрирует услуги AI-разработчика:
каталог услуг, прайс-лист, контакты и информацию о компании.

Каталог услуг и цены хранятся в файле `data/services.json` — Python-код при
изменении цен или добавлении услуг менять не нужно.

## Структура проекта

```text
vk-catalog-bot/
│
├── bot.py            # Точка входа: создание бота и запуск Long Poll
├── config.py         # Загрузка .env и получение VK-токена
├── services.py       # Работа с JSON-каталогом услуг и форматирование цен
├── keyboards.py      # Все клавиатуры бота
├── handlers.py       # Обработчики сообщений и кнопок
│
├── data/
│   └── services.json # Каталог услуг и цены
│
├── .env              # Токен (не попадает в Git)
├── .env.example      # Пример файла с переменными окружения
├── .gitignore
├── requirements.txt
└── README.md
```

## 1. Клонирование проекта

```bash
git clone <repository-url>
cd vk-catalog-bot
```

## 2. Создание виртуального окружения

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 4. Настройка `.env`

Создайте файл `.env` в корне проекта и добавьте токен сообщества:

```env
VK_TOKEN=токен_сообщества
```

## 5. Запуск

```bash
python bot.py
```

Бот подключится к Long Poll серверу ВКонтакте и начнёт отвечать на сообщения.

## Как создать сообщество и получить токен

1. Откройте [vk.com](https://vk.com) и в левом меню выберите **«Сообщества»** →
   **«Создать сообщество»**.
2. Выберите тип сообщества (например, **«Бизнес»**) и задайте название.
3. Перейдите в **«Управление»** (кнопка с тремя точками под обложкой).
4. Откройте раздел **«API использование»** (или «Работа с API»).
5. На вкладке **«Ключи доступа»** нажмите **«Создать ключ»**.
6. Отметьте права доступа:
   - **Разрешить приложению отправлять сообщения** (обязательно);
   - при необходимости — доступ к фотографиям и документам.
7. Подтвердите действие кодом из SMS и скопируйте созданный ключ.
8. Вставьте ключ в файл `.env`:

   ```env
   VK_TOKEN=vk1.a....
   ```

## Как включить Long Poll

1. В управлении сообществом откройте **«API использование»**.
2. Перейдите на вкладку **«Long Poll»**.
3. Включите **Long Poll сервер** и выберите события:
   - **Входящие сообщения** (обязательно);
   - остальные события — по желанию.
4. Убедитесь, что версия API — **5.131** или выше.

## Как разрешить боту писать первым

Чтобы пользователи могли написать сообществу:

1. В управлении сообществом откройте **«Сообщения»**.
2. Включите **«Возможности сообщений»**.
3. При желании включите кнопку **«Написать сообщение»** на главной странице.

## Как протестировать бота

1. Запустите бота: `python bot.py`.
2. Откройте диалог с вашим сообществом и отправьте `/start` или `Начать`.
3. Бот покажет главное меню с кнопками:
   - 🤖 Каталог услуг
   - 💰 Прайс-лист
   - 📩 Связаться
   - ℹ️ О компании
4. Выберите услугу в каталоге — бот покажет карточку с описанием, ценой,
   сроком и технологиями.
5. Неизвестные сообщения бот обрабатывает вежливой подсказкой и меню.

## Как добавить услугу или изменить цену

Отредактируйте `data/services.json` — добавьте новый объект в массив
`services` или измените поле `price_from`. Перезапускать бота не обязательно:
каталог перечитывается из файла при каждом запросе.

```json
{
  "id": "new_service",
  "name": "Новая услуга",
  "short_name": "✨ Новая услуга",
  "description": "Описание услуги.",
  "price_from": 30000,
  "currency": "RUB",
  "duration": "от 4 рабочих дней",
  "technologies": ["Python"]
}
```
