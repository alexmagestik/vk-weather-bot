# Погода — CLI + VK-бот (OpenWeatherMap)

Проект демонстрирует работу с OpenWeatherMap API в двух интерфейсах:

- **CLI-приложение** (`weather_app.py`) — погода в терминале;
- **VK-бот** (`bot.py`) на библиотеке [vkbottle](https://vkbottle.readthedocs.io/ru/latest/),
  работающий через Long Poll.

Вся работа с API вынесена в отдельный модуль `weather_api.py`, поэтому бот и CLI
используют одни и те же функции. Оформление текста лежит в `weather_format.py`.

## Возможности

- **Текущая погода** по названию города или координатам.
- **Геолокация** — бот принимает местоположение (кнопка «Отправить местоположение»)
  и показывает погоду в точке; в CLI — определение города по координатам.
- **Сравнение городов** — погода в двух городах и «кто теплее».
- **Прогноз на 5 дней** (3-часовые интервалы).
- **Качество воздуха** — индекс AQI и основные загрязнители.
- **Геокодинг** названия города в координаты и обратный геокодинг.
- **Кэширование** текущей погоды (`weather_cache.json`, свежесть — 3 часа).
- **Ретраи** при `429` и временных сетевых сбоях (`1s → 10s → 60s`).
- Понятные сообщения об ошибках на русском, без трейсбеков.

## Требования

- Python 3.10+.
- API-ключ OpenWeatherMap — <https://openweathermap.org/api>.
- Для бота — токен сообщества ВКонтакте (см. ниже).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка `.env`

Создайте в корне проекта файл `.env`:

```env
OPENWEATHER_API_KEY=ваш_ключ_openweather
VK_TOKEN=ваш_токен_vk
```

`VK_TOKEN` нужен только для бота. Файл `.env` добавлен в `.gitignore`.

## CLI-приложение

```bash
python weather_app.py
```

Меню:

```
===== Погода =====
1 — Погода по названию города
2 — Погода по координатам
3 — Сравнить два города
4 — Прогноз на 5 дней
5 — Качество воздуха
6 — Геолокация: определить город по координатам
0 — Выход
```

Пример вывода:

```
Погода в «Москва»
Координаты: 55.75, 37.62
Температура: +8°C (ощущается как +6°C)
Состояние: дождь
Влажность: 73%, давление 1019 гПа
Ветер: 3.19 м/с
```

## VK-бот

```bash
python bot.py
```

Бот подключается к Long Poll и отвечает на сообщения. Меню бота:

| Кнопка | Действие |
| --- | --- |
| 🌤 Погода в городе | текущая погода по названию города |
| 📍 Геолокация | погода по координатам из присланной геолокации |
| ⚖️ Сравнить города | погода в двух городах и кто теплее |
| 📅 Прогноз на 5 дней | прогноз по 3-часовым интервалам |
| 🌫 Качество воздуха | индекс AQI и основные загрязнители |
| ❓ Помощь | справка по командам |

Диалог поддерживает отмену («✖️ Отмена») и возврат в меню («🏠 Меню»), а также
команду `/start`.

### Как создать сообщество и получить токен

1. На [vk.com](https://vk.com) откройте **«Сообщества» → «Создать сообщество»**.
2. В управлении сообществом перейдите в **«Работа с API» → «Ключи доступа»**.
3. Нажмите **«Создать ключ»** и отметьте право
   **«Разрешить приложению отправлять сообщения»**.
4. Скопируйте ключ в `.env` как `VK_TOKEN`.

### Как включить Long Poll

1. В управлении сообществом: **«Работа с API» → «Long Poll API»**.
2. Включите Long Poll и событие **«Входящие сообщения»**.
3. Версия API — 5.131 или выше.
4. В разделе **«Сообщения» → «Возможности сообщений»** разрешите писать сообществу.

## Кэширование

Успешные ответы о **текущей погоде** складываются в `weather_cache.json` (список
записей с метаданными `city`, `lat`, `lon`, `fetched_at`). Запись моложе 3 часов
отдаётся без обращения к API; при обновлении координаты сравниваются с допуском
~1 км. Прогноз и качество воздуха запрашиваются напрямую (без кэша).

## Обработка ошибок и ретраи

| Ситуация | Сообщение |
| --- | --- |
| Неверный ключ (`401`) | `Невалидный API-ключ. Проверьте OPENWEATHER_API_KEY в файле .env.` |
| Ничего не найдено (`404`) | `Данные не найдены (ошибка 404) ...` |
| Лимит запросов (`429`) | `Превышен лимит запросов (ошибка 429). Повторите попытку позже.` |
| Город не найден | `Город «...» не найден. Проверьте название.` |
| Нет сети | `Нет связи с сервером погоды после нескольких попыток.` |

На `429` и временные сетевые сбои выполняется до 3 повторов с паузами `1s`, `10s`,
`60s`.

## Используемые эндпоинты OpenWeatherMap

- Geocoding API (прямой и обратный геокодинг);
- Current Weather Data (текущая погода);
- 5 day / 3 hour Forecast (прогноз);
- Air Pollution API (загрязнение воздуха).
